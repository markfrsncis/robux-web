# robux-web

A premium, animated multi-page portfolio built with **Next.js (App Router)**, **Tailwind CSS**, and **Framer Motion**.

## Pages
- `/` Home
- `/about` About
- `/projects` Projects
- `/contact` Contact

## Run locally
```bash
npm install
npm run dev
```
Open http://localhost:3000

## Build
```bash
npm run build
npm run start
```
