# robux-web

Award-style multi-page portfolio using only **HTML, CSS, and JavaScript**.

## Pages
- `index.html`
- `about.html`
- `projects.html`
- `contact.html`

## Run
Open `index.html` directly, or run a local server:

```bash
python3 -m http.server 5500
```

Then visit `http://localhost:5500`.
